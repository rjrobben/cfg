|=-----------------------------------------------------------------------=|
|=-------------------=[ dotfiles via bare git repo ]=-------------------=|
|=-----------------------------------------------------------------------=|

my dotfiles live in a bare git repo at ~/.cfg, with the work-tree set
to my home dir. the `config` alias is just git pointed at those two
places. files are invisible to it until i explicitly add them.

repo: git@github.com:rjrobben/cfg.git


--[ the alias

put this in ~/.zshrc:

    alias config='git --git-dir=$HOME/.cfg/ --work-tree=$HOME'

then `config` works exactly like `git`, from any directory.


--[ setup on a new machine

clone the bare repo, then check out the files into home.

    git clone --bare git@github.com:rjrobben/cfg.git $HOME/.cfg
    alias config='git --git-dir=$HOME/.cfg/ --work-tree=$HOME'
    config checkout

if checkout complains about existing files (e.g. .zshrc already there),
back them up and retry:

    mkdir -p ~/.cfg-backup
    config checkout 2>&1 | egrep "\s+\." | awk {'print $1'} | \
      xargs -I{} mv {} ~/.cfg-backup/{}
    config checkout

finally, hide all the untracked junk in home so status stays clean:

    config config --local status.showUntrackedFiles no


--[ daily use

    config status
    config add ~/.config/nvim/init.lua      # add SPECIFIC files only
    config commit -m "message"
    config push


--[ gotcha: never add a whole directory

do NOT run `config add .` or `config add somedir/`.

if that dir contains its own .git (any cloned project under ~), git
records it as a submodule pointer (mode 160000) instead of ignoring
it. status then nags forever about it.

to undo an accidental one (does not delete the real project):

    config rm --cached path/to/project
    config commit -m "stop tracking path/to/project"


--[ how it fits together

        +------------------+         +------------------+
        |   ~/.cfg  (git    |  tracks |  ~  (work-tree)  |
        |   data: commits,  |-------->|  only files i    |
        |   branches)       |         |  explicitly add  |
        +------------------+         +------------------+
                 |
                 | push/pull
                 v
        github.com/rjrobben/cfg


|=-----------------------------------------------------------------------=|
|=-------------=[ inkscape-figures flow (new machine) ]=----------------=|
|=-----------------------------------------------------------------------=|

draw figures in inkscape from nvim. in a markdown/typst buffer:

  insert-mode Ctrl+f  -> type a title on the line, hit it: makes
                         figures/<title>.svg, opens inkscape, replaces
                         the line with ![](figures/<title>.svg)
  normal-mode Ctrl+f  -> `choose` picker to reopen an existing figure

while `inkscape-figures watch` runs, hitting Ctrl+S in inkscape
auto-exports the svg. the nvim keymaps live in ~/.config/nvim/init.lua
(synced via cfg, so they arrive with `config checkout`).


--[ IMPORTANT: use my fork, not pypi

upstream inkscape-figures only does LaTeX. my fork adds typst +
markdown templates and the --format flag that the nvim keymap needs.
`pip install inkscape-figures` gives vanilla upstream and the flow
breaks. always install from my fork:

    github.com/rjrobben/inkscape-figures


--[ install (macOS)

    brew install inkscape          # the `inkscape` CLI
    brew install choose-gui        # the `choose` picker used by edit
    git clone git@github.com:rjrobben/inkscape-figures.git \
        ~/repos/inkscape-figures
    pip install ~/repos/inkscape-figures   # under my pyenv python (3.12.x)

check all three are on PATH:

    which inkscape inkscape-figures choose


--[ run the watcher

auto-export only happens while the watcher is running. start it in a
spare terminal (or tmux pane) when working on figures:

    inkscape-figures watch


--[ deps at a glance

        +-------------------+   open/export   +-----------+
        | inkscape (brew)   |<----------------| inkscape- |
        +-------------------+                 | figures   |
        +-------------------+   edit picker   | (my fork) |
        | choose-gui (brew) |<----------------|           |
        +-------------------+                 +-----------+
                                                    ^ Ctrl+f
                                              ~/.config/nvim/init.lua
